# Supermarket API

REST API для управления товарами, поставками, продажами, остатками и ценами супермаркета.

## Возможности

* управление типами товаров;
* управление товарами;
* управление поставщиками;
* управление ценами;
* учет поставок;
* учет продаж;
* учет списаний;
* учет складских остатков;
* автоматическое изменение остатков при поставках, продажах и списаниях;
* Swagger-документация.

## Запуск с помощью Docker Compose

### Требования

* Docker;
* Docker Compose.

### Настройка

Перед запуском создайте файл `.env` в корне проекта и заполните необходимые переменные окружения:

```env
POSTGRES_DB=supermarket
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
LOG_LEVEL=debug
```

### Запуск проекта

Соберите и запустите все сервисы:

```bash
docker compose up --build
```

Для запуска в фоновом режиме:

```bash
docker compose up -d --build
```

### Состав проекта

При запуске будут созданы следующие сервисы:

* **db** — база данных PostgreSQL;
* **migrate** — применение миграций базы данных;
* **api** — REST API приложения;
* **frontend** — веб-интерфейс приложения.

### Доступные адреса

После запуска будут доступны:

* Frontend: `http://localhost`
* REST API: `http://localhost:8080`
* Swagger UI: `http://localhost:8080/swagger/index.html`

### Остановка

Остановить контейнеры:

```bash
docker compose down
```

Остановить контейнеры и удалить том с базой данных:

```bash
docker compose down -v
```
